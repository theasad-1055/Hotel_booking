# 🏨 Hotel Booking Data Analysis

## 📌 Project Overview

This project analyzes hotel booking data to identify booking patterns, 
cancellation trends, revenue opportunities, and customer behavior 
for City Hotel and Resort Hotel.

The analysis was performed using Python, Pandas, NumPy, Matplotlib, 
and Seaborn.

---

## 🎯 Business Problem

Hotels are experiencing high booking cancellation rates, which can 
lead to revenue loss and underutilized rooms.

The objective of this project is to analyze hotel booking data and 
identify factors related to cancellations, booking behavior, and 
average daily rates.

---

## ❓ Key Questions

- What percentage of hotel bookings are cancelled?
- Which hotel has a higher cancellation rate?
- How does Average Daily Rate (ADR) vary over time?
- Which countries generate the most bookings?
- How does booking behavior differ between City Hotel and Resort Hotel?
- What factors are associated with booking cancellations?
- Which months have higher booking demand?
